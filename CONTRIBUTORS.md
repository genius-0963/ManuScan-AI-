## Contribution Types

We recognize all types of contributions:

- 💻 **Code** - Backend, frontend, algorithms
- 📖 **Documentation** - README, guides, API docs
- 🎨 **Design** - UI/UX, logos, graphics
- 🐛 **Bug Reports** - Finding and reporting issues
- 💡 **Ideas** - Feature suggestions and improvements
- 🤔 **Answering Questions** - Helping other users
- ⚠️ **Tests** - Writing and improving tests
- 🔧 **Tools** - Build tools, CI/CD, infrastructure
- 🌍 **Translation** - Internationalization
- 📢 **Talks** - Presentations about the project
- 📝 **Tutorials** - Educational content
- 📹 **Videos** - Demos and explanations
- 💬 **Community** - Discord, discussions, support
- 🔍 **Research** - Academic papers, benchmarks
- 📊 **Data** - Training data, test cases
- 💰 **Financial** - Sponsorship and funding
- 🚇 **Infrastructure** - Hosting, domains, services
- 🚧 **Maintenance** - Keeping the project running

This project builds on the amazing work of many open source projects:
- [Open3D](https://github.com/isl-org/Open3D) - 3D geometry processing

- [Three.js](https://github.com/mrdoob/three.js) - 3D visualization
- [TensorFlow.js](https://github.com/tensorflow/tfjs) - Browser-based ML
- [React](https://github.com/facebook/react) - UI framework
- [Vite](https://github.com/vitejs/vite) - Build tool
