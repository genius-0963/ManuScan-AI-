## System Requirements

### Minimum Requirements

- **OS**: macOS, Linux, or Windows 10+
- **Python**: 3.9 or higher
- **Node.js**: 18.0 or higher
- **RAM**: 8GB minimum, 16GB recommended
- **Disk Space**: 5GB free space

### Optional (for GPU acceleration)

- **CUDA**: 11.7 or higher
- **GPU**: NVIDIA GPU with 4GB+ VRAM
- **cuDNN**: Compatible with CUDA version

### Recommended

- **GPU**: NVIDIA RTX 3060 or better
- **RAM**: 32GB
- **SSD**: For faster I/O

## Backend Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/manuscan-ai.git
cd manuscan-ai
```

Or if you have the files locally, navigate to the directory:
```bash
cd "ManuScan AI - Intelligent 3D Geometry Analysis Engine"
```

### 2. Create Virtual Environment

**On macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**On Windows:**
```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Install Python Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

This will install:
- PyTorch with CUDA support (if available)
- PyTorch Geometric for GNNs
- Open3D for geometry processing
- TensorFlow.js for model export
- And all other dependencies

**Installation time**: 5-15 minutes depending on internet speed

### 4. Verify Backend Installation

```bash
python setup_verification.py
```

You should see:
```
✅ All checks passed! ManuScan AI is ready to use.
```

### 5. Test Backend Components

```bash
# Test geometry processing
python -c "from backend.geometry import MeshProcessor; print('✓ Geometry OK')"

# Test models
python -c "from backend.models import create_model; print('✓ Models OK')"

# Run example
python example_usage.py
```

## Frontend Installation

### 1. Install Node.js Dependencies

```bash
cd frontend
npm install
```

This will install:
- Vite (build tool)
- Three.js (3D rendering)
- TensorFlow.js (AI inference)
- TypeScript
- And all dependencies

**Installation time**: 2-5 minutes

### 2. Verify Frontend Setup

```bash
# Check if node_modules exists
ls node_modules | head -5

# Should see folders like:
# @tensorflow
# three
# vite
```

### 3. Start Development Server

```bash
npm run dev
```

The application will open at `http://localhost:3000`

You should see:
```
  VITE v5.0.0  ready in 1234 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

## Troubleshooting

### Issue: "ModuleNotFoundError: No module named 'torch'"

**Solution:**
```bash
pip install torch torchvision torchaudio
```

### Issue: "CUDA not available"

**Solution 1**: Install CUDA toolkit from NVIDIA
**Solution 2**: Use CPU mode (slower but works)
```python
# In your code, use:
processor = MeshProcessor(use_gpu=False)
```

### Issue: "npm ERR! code ERESOLVE"

**Solution:**
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
```

### Issue: "Port 3000 already in use"

**Solution:**
```bash
# Change port in vite.config.ts
# Or kill process on port 3000
lsof -ti:3000 | xargs kill -9  # macOS/Linux
netstat -ano | findstr :3000   # Windows
```

### Issue: "python-occ-core installation fails"

**Solution:**
```bash
# STEP file support is optional
# You can comment out python-occ-core in requirements.txt
# STL files will still work perfectly
```

### Issue: "Out of memory during training"

**Solution:**
```bash
# Reduce batch size
export BATCH_SIZE=4
./scripts/train_model.sh

# Or in Python:
trainer = Trainer(batch_size=4)
```

### Issue: "WebGL not supported"

**Solution:**
- Update your browser to latest version
- Enable hardware acceleration in browser settings
- Try a different browser (Chrome recommended)

## System-Specific Notes

### macOS

- Use Homebrew for dependencies: `brew install python@3.9 node`
- CUDA not available on macOS (use CPU mode)
- MPS backend coming soon for Apple Silicon

### Linux

- Install CUDA from NVIDIA website
- May need `libgl1-mesa-glx`: `apt-get install libgl1-mesa-glx`
- Use virtual environment to avoid system conflicts

### Windows

- Use WSL2 for better compatibility
- Install Visual Studio Build Tools for C++ dependencies
- Use Anaconda for easier package management
